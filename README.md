# K-pop in Australia

A data visualisation project exploring K-pop's surprising presence in the Australian music landscape.

## About

This project explores how K-pop has grown in Australia from 2015 to 2025 — a market that isn't in the global top 10 for K-pop streaming, but where the *K-pop Demon Hunters* soundtrack held #1 on ARIA charts for 10+ consecutive weeks in 2025. Through 12 visualisations including 3 maps, this project tells the story of K-pop's quieter but devoted Australian wave.

## Story Structure

1. **The Rise** — K-pop's growth in Australian Spotify charts (2015–2025)
2. **The Map** — Which Australian states are most into K-pop?
3. **The Stages** — K-pop concert venues across Australia
4. **The Sound** — What makes Australian-popular K-pop unique?
5. **The World** — Australia's place in the global K-pop landscape

## Data Sources

- [kworb.net](https://kworb.net/spotify/country/au_daily.html) — Australian Spotify charts
- [Google Trends](https://trends.google.com/trends/?geo=AU) — Search interest by state
- [ARIA Charts](https://www.aria.com.au/charts) — Official Australian music charts
- [Kaggle Spotify Datasets](https://www.kaggle.com/datasets) — Audio features
- [Setlist.fm](https://www.setlist.fm/) & [Wikipedia](https://en.wikipedia.org/) — Concert venues
- [Australian Bureau of Statistics](https://www.abs.gov.au/) — Population by state
- [Luminate Data](https://luminatedata.com/) — Global K-pop streaming
